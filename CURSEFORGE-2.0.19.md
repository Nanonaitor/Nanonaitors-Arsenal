# Nanonaitor's Arsenal 2.0.19 - Minecraft 1.12.2

## Configuration hotfixes

- Disabled weapon families are now hidden from JEI as well as the Arsenal creative tab.
- Disabled Arsenal enchantments remain registered for existing-world safety, but cannot be obtained, applied or provide their effects.
- Disabled Arsenal enchanted books are hidden from JEI and the Arsenal creative tab.
- Fixed existing worlds reporting Arsenal enchantments as missing registry entries when enchantments were disabled in the configuration.
- Fixed the in-game configuration title displaying broken encoding characters.
- Clarified that Recovery and Breeched apply to Arsenal shields.

## Notes

- Replace Arsenal 2.0.18 with this JAR; do not keep both versions installed.
- Restart Minecraft after updating.
- Back up important worlds before changing mod versions.
- Install the same Arsenal version on the client and server for multiplayer.
